GUIA RAPIDA - TIENDATECNOLOGIAAPI
=================================

REQUISITOS
- Visual Studio 2022.
- Carga de trabajo: ASP.NET y desarrollo web.
- .NET 8 SDK.

EJECUCION
1) Descomprime el ZIP.
2) Abre TiendaTecnologiaAPI.sln.
3) Esperar a  que Visual Studio restaure los paquetes NuGet.
4) Seleccionar el perfil HTTPS.
5) Presionar F5 o el boton Ejecutar.
6) Debemos a proceder a abrir Swagger.

PRUEBA MINIMA PARA LA TAREA
1) GET /api/Marcas -> demuestra SELECT.
2) POST /api/Marcas con:
   {
     "nombre": "HP"
   }
3) Copia el idMarca que devuelve el POST.
4) PUT /api/Marcas/{id} usando ese mismo id, por ejemplo:
   {
     "idMarca": 4,
     "nombre": "HP Inc."
   }
5) Ejecuta de nuevo GET /api/Marcas y comprueba el cambio.
